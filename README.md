## Android focus timer alerts

Start a focus timer and allow notifications when Android asks. To receive
on-time alerts while the app is in the background, open **Settings → Exact
timer alerts** in the app and allow **Alarms & reminders** if Android asks.
Without that access, Android may delay the alert while the phone is idle.

To test on a phone, start a short timer, press Home or lock the screen, and
check for one completion alert. Repeat with the timer paused or stopped and
verify that no alert appears at the original deadline.
